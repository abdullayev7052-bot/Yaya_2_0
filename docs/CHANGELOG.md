# Yaya — oʻzgarishlar tarixi

## v2.8 (ishlab chiqilmoqda)
- Laboratoriya boʻlimi (qabul qilingan smenalar uchun sifat koʻrsatkichlari, limitlar, qizil/sariq/yashil holatlar).
- Boʻsh joy tuzatildi (smena yorliqlari ostida).
- Balansi 0 boʻlgan xonadonni tarixi bilan butunlay oʻchirish.
- Smena yopilishi bilan qabul qiluvchilarga darhol koʻrinadi.

_APK keyingi yakuniy yigʻishda beriladi._
